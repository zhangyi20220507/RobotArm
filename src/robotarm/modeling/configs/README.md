# Experiment configs

Keep reviewed training arguments or LeRobot config files here. Record at least:

- source dataset path and `repo_id`;
- converted session IDs;
- policy type and checkpoint source;
- batch size, steps, seed, and learning-rate changes;
- LeRobot, PyTorch, and CUDA versions;
- evaluation results and known dataset exclusions.

Do not store Hugging Face or Weights & Biases tokens in this directory.
